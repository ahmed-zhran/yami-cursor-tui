# yami-cursor-tui

Terminal chat UI for driving a Cursor agent session from the project directory.

## Setup

```bash
pnpm install
pnpm start          # or: pnpm build && yami (when installed as a package)
pnpm test
pnpm lint:deps
```

`yami` opens an Ink TUI with an empty stacked transcript and a bottom prompt. Agent wiring comes in later tickets.
